# ecommerce-syntaxwear

Um projeto de loja online estilizado para a formação DevQuest 2.0. O código consiste em HTML básico e folhas de estilo CSS separadas por componentes.

## Estrutura do projeto

- `index.html` – página principal
- `css/` – estilos globais e de componentes
  - Arquivos globais: `base.css`, `reset.css`, `variable.css`
  - `components/` – estilos específicos por seção:
    - `header.css`
    - `footer.css`
    - `hero.css`
    - `product-category.css`
    - `product-grid.css`
- `images/` – imagens organizadas por categoria:
  - `banners/` – hero e mobile
  - `favicons/` – ícones de botão
  - `icons/` – SVGs de interface (hamburger, bag, redes sociais etc.)
  - `logo/` – logotipo da loja
  - `products/` – fotos de produtos e backgrounds (casual, esportes, futurista, moderno, modelos etc.)


## Como usar

1. Abra o arquivo `index.html` em um navegador moderno.
2. Edite os estilos em `css/` conforme necessário.
3. Adicione ou modifique imagens na pasta `images/`.

## Ferramentas

Nenhuma dependência de build; é um site estático implementado com HTML e CSS puros.
